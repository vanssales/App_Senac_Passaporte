Este projeto é um passaporte virutal de um evento que é realizado em uma escola. Os visitantes poderã0 encontrar as oficinas e horários e escolher participar. O aplicativo deve registrar as oficinas que um visitante participou (concluiu) e gerar um relatório administrativo.

Este é um projeto feito em React usando Vite na versão mais recente. Ele faz uso do banco de dados do Supabase e a sua API.
